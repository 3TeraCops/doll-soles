# Форма заказа — 3D-печать кукольных подошв

Статический сайт без сборки и зависимостей: `index.html`, `styles.css`, `app.js`.

## Что работает

- Несколько позиций в одном заказе: модель (выпадающий список с поиском), цвет, количество пар.
- Удаление позиции: иконка показывается только когда позиций 2 и больше.
- Кнопка «Оформить заказ» создаёт номер вида `3D-2481` (счётчик в `localStorage`),
  показывает экран «Заказ оформлен» со списком позиций и итогом по парам.
- «Вернуться к форме» — сброс к одной позиции.
- Копирование номера заказа.
- Адаптив: мобильный (до 640 px) и десктопный вид.

## Что подключить дальше

Уведомление в Telegram: в `app.js` задайте адрес бэкенда

```js
const TELEGRAM_ENDPOINT = ""; // POST { number, createdAt, positions, totalPairs }
```

Токен бота нельзя держать во фронтенде — нужен прокси (Cloudflare Worker, Vercel
Function, Netlify Function), который принимает JSON и вызывает `sendMessage`.

## Локальный запуск

```bash
node server.js
# http://localhost:4173
```

или любой статический сервер: `npx serve .`, `python -m http.server`.

## Деплой

Сайт статический, подойдёт любой бесплатный хостинг:

- **Netlify Drop** — перетащить папку на https://app.netlify.com/drop
- **Cloudflare Pages** — Direct Upload, папка целиком
- **Vercel** — `npx vercel --prod` (нужен аккаунт)
- **GitHub Pages** — залить содержимое в репозиторий, Settings → Pages

Папка для загрузки: эта (`order-form`), без `server.js` (он только для локального
просмотра).
